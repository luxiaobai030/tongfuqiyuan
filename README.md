# 同福奇缘 · Godot 移植版

Flash 小游戏《同福奇缘》（武林外传 · 同福客栈模拟经营）的 Godot 4.7 移植版。
画面、剧情、数值全部取自原版 SWF，没有重画素材。

想直接玩：从 Releases 里下 `tongfuqiyuan.exe`（文件名是拼音，GitHub 会把中文名改成 default.exe），双击即玩，不用装 Godot。

## 怎么玩

1. 装 Godot 4.7
2. 用 Godot 的「导入」选 `game/project.godot`（也可以直接双击这个文件）
3. 编辑器里按 **F5** 运行；窗口 800×600，可拉伸（保持比例）

## 操作

| 干什么 | 怎么按 |
| --- | --- |
| 选按钮、看说明 | 鼠标点；鼠标悬停在按钮上会像原版那样换画面、弹出说明 |
| 剧情继续 | `空格` |
| 战斗 · 先机 / 后发 | `A` / `D` |
| 技能 | `Z` `X` `C` `V` `B` `N` |
| 逃跑 | `Q` |
| 打开 / 关掉菜单 | 点右上角那块「菜单」木牌，或按 `Tab` |
| 存档 / 读档 | 菜单里点（三个档位随便挑）；`F5` 快速存档、`F9` 快速读档，都存到档位一 |
| 隐藏道具图鉴 | 菜单里点「隐藏道具」；`Esc` 关掉任何框 |

这些按键能做的事，直接拿鼠标点按钮也一样。

## 玩法

标题 → 开门营业 → 选难度（江湖小虾 / 武林高手）→ 开场剧情（含一场战斗）→ 第 1 天 → 晚上 → 休息 → 第 2 天……
一直经营到第 100 天出结局（共 5 种；完美结局要选高难度，且威望、完美度都在 100 以上）。

## 额外加的功能（原版没有）

- **存档 / 读档**：一共三个档位，写着「第 n 天 + 存档时刻」，还空着的写「（空档位）」。
  标题页卷轴底下有一块「读档」木牌，进游戏之后从右上角「菜单」里随时能存能读；
  覆盖已经存过的档位要点两下（先变「再点一下重写」）。
  存档文件在 `%APPDATA%\Godot\app_userdata\同福奇缘\`，档位一沿用原来的文件名，
  所以老存档不用搬家、直接就能读。
- **右上角菜单**：存档、读档、隐藏道具、关闭都在这儿。
- **界面画风**：新加的菜单、存档框、道具框、标题页那块读档木牌，一律照抄原版自己的界面 ——
  米黄底 + 深棕云纹边 + 朱红隶书字，底板和边框是直接从标题页底图上抠的像素。
- **隐藏道具图鉴**：菜单里点「隐藏道具」打开，右上角木牌上会写着「隐藏道具 n/19」。
  前半是倾城装 4 件，后半是十八里铺淘宝珍品 15 种；拿到过的显示名字和效果，**没拿到的显示 `？？？`**。
  框开着的时候底下的按钮点不到，战斗键也不会误发。
- **伤害飘字**：战斗里敌我掉血 / 回血时，人物身上会飘出数字（敌人掉血黄字、自己掉血红字、回血绿字）。
- **战斗奖励翻倍**：打赢一场的结算奖励是原版的两倍 —— 生命 +6、修为 +10、技力 +20、威望 +2、铜钱 +100。

## 自己导出 exe

```
# 1. 装导出模板：编辑器 → 编辑器 → 管理导出模板 → 下载（约 1GB）
# 2. 先建好目标文件夹（没建会报「给定的导出路径不存在」），再执行：
Godot.exe --headless --path game --export-release "Windows Desktop" "..\导出\同福奇缘.exe"
```
