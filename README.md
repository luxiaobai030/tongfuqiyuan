# 同福奇缘 · Godot 移植版

把 Flash 小游戏《同福奇缘》（武林外传同福客栈模拟经营）搬到 Godot 4.7。
原版画面、剧情、数值全部来自原版 SWF，没有重画素材。

## 怎么玩

1. 打开 Godot 4.7（本机在 `F:\APP\Godot\Godot.exe`）
2. 「导入」→ 选择 `game/project.godot`（或者直接双击这个文件）
3. 在编辑器里按 **F5** 运行；窗口 800×600，可自由拉伸（保持比例）
   （注意：这里说的 F5 是编辑器的「运行」；游戏跑起来之后，F5 是存档，见下面第 5 条）

操作方式与原版一致：**鼠标点按钮，鼠标悬停在按钮上会像原版那样切换画面、弹出说明**
（人物属性页的说明框、客栈属性图标的「花费 / 收益」提示都是原版按钮自带的悬停美术）。
原版里用键盘的按钮也保留：剧情继续 = `空格`，战斗先机 / 后发 = `A` / `D`，
技能 = `Z` `X` `C` `V` `B` `N`，逃跑 = `Q`（也都可以直接点）。
另外加了两个便利键：`F5` 存盘、`F9` 读档（存档在 `%APPDATA%\Godot\app_userdata\同福奇缘\`）。
再加上右上角那个常驻的小开关「隐藏道具 n/19」：

* 点它、或者按 `Tab`，弹出**隐藏道具图鉴** —— 倾城装四件 + 十八里铺淘宝珍品十五种，
  拿到过的显示名字和效果，**没拿到的显示 `？？？`**。再点一次（或者按 `Esc`、点框外面）收起。
* 图鉴框里还有 **存档 / 读档** 两个按钮，和 `F5` / `F9` 是一回事：存档会记住
  变量表（钱 / 天数 / 好感 / 隐藏道具收集进度……）和当前进度位置，读档就回到存档那一刻。
* 图鉴框开着的时候会挡住下面的画面，点不到背后的按钮，`Z` `X` `C` 这些战斗键也不会误发。

## 玩法主线

标题 → 开门营业 → 选难度（江湖小虾 / 武林高手）→ 开场剧情（含一场战斗）
→ 第 1 天晚上 → 休息 → 第 2 天早上大堂 → 开门营业 → 晚上 → 休息 → ……
一直经营到第 100 天触发结局（共 5 种结局，完美结局要求高难度 + 威望/完美度 100 以上）。

仓库里**没有**下面这几样，它们要么太大、要么能重新生成（见 `.gitignore`）。
玩游戏本身用不到它们 —— 克隆下来直接用 Godot 打开 `game/project.godot` 就能跑。

| 没进仓库 | 为什么 | 怎么弄回来 |
| --- | --- | --- |
| `导出/` | 单个 exe 就 300MB，超了托管站的单文件上限 | 用上面「自己重新导出」的命令重新导一次 |
| `decompiled/` | 3GB 的反编译中间产物 | 用 `tools/extract_swf.py` 从 `原版/同福奇缘.swf` 重新解一遍 |
| `game/.godot/` | Godot 的导入缓存，可重建 | 用 Godot 打开一次工程，自动生成 |
| `body_uncompressed.bin` | SWF 解包的临时文件 | 解包脚本自己会生成 |

## 实现方式

* **时间轴**：原版是 4907 帧的 Flash 时间轴。移植版按 19fps 逐帧推进，遇到有脚本的帧就执行
  转译后的逻辑；脚本里的 `stop()` 会让时间轴停下等玩家操作，`play()` / `gotoAndPlay()` 继续。
* **画面**：原版逐帧整幅画面 + 动态文本框 + 按钮热区。
  * 背景直接取 FFDec 导出的 `decompiled/frames`：人物动画、静态美术字全都烧在画面里，
    所以每一帧都和原版播放时看到的一模一样（4907 帧里 3513 个关键帧、3286 张唯一画面）。
  * 关键帧是**逐帧做精确像素比较**得到的：只有整幅画面和上一个关键帧完全一样时才合并，
    战斗里出招/移动/受击这种「只有局部在动」的帧一帧都不会丢。
  * 为什么不用「人物独立成层」（做过一版，已按用户要求改回）：原版里角色处在根舞台最底层，
    按钮文字是画在角色**上面**的（战斗的「先机 / 后发」就在黑衣人的图层之上）。移植版如果把人物
    抠出来单独播，就只能画在整幅画面最上面，反而会盖住这些按钮文字，战斗里容易点不到。
    所以现在人物动画和原版录制逐帧一致：停帧等玩家操作时画面不动，但按钮、文字、点击一律正常。
  * 重建：`python tools/build_assets.py`（背景 + 索引）。
  * 按钮悬停态和「被说明框盖住的文本框」：`python tools/build_button_over.py`
    （生成 `assets/btnover/` + `data/buttons.json` + `data/hidden.json`）。
* **交互**：按钮热区按 id 复用节点，换帧只更新位置和文字、不重建，所以鼠标悬停 / 移开的原版行为
  （rollOver 换帧看说明、rollOut 切回原画面）都能正常工作，也不会把鼠标底下的按钮释放掉。
* **动态文本框**：位置、字体、字号、颜色、对齐方式都是从 SWF 的 DefineEditText 标签里读出来的，
  所以「金钱 / 天数 / 威望 / 完美度 / 人物属性 / 客栈属性 / 战斗血量」等都是实时数值。
  少数文本框在原版里用的是「设备字体」（黑体 / Arial，SWF 里不含字形，靠玩家系统字体渲染），
  移植版会去系统里找黑体 / Arial 来显示，找不到就退回内嵌字体。
* **声音**：原版 5 首 BGM 都 ≥39 秒、最长的音效只有 6.4 秒，所以按**时长 ≥20 秒**判定是不是背景音乐：
  背景音乐循环播放、同一首重复触发不会重新开始，其余走音效池。
* **脚本**：`tools/as2_to_gd.py` 把 ActionScript 2 转成 GDScript，逻辑逐行照搬。
  想改逻辑请改 `tools/` 里的脚本再重新生成 `logic.gd`，不要手改生成物。

## 与原版的差异（有意为之）

1. 原版「开门营业」这条主线里从没给 `hp` 赋过初值（原版遗留 bug，属性面板上生命是空的），
   移植版给了 `hp = 100` 的初值。
2. ActionScript 的变量名不区分大小写，原版里同时存在 `LB_chenghao` / `LB_chenhao` 这类
   拼写不一致的名字，移植版统一按小写存储并把错别字别名指过去，保证面板能显示出称号。
3. 原版按钮的悬停高亮在 Flash 里是另一套美术（DefineButton2 的 over 状态），移植版把 over
   比 up 多出来的那部分抠成一张透明贴图，鼠标压上去时叠在原画面上，和原版一致（见修复记录）。
   另外照旧保留一层很淡的白色高亮，让热区看起来更明显一点。
4. 原版「玩玩其他小游戏」按钮指向的站外链接不再打开浏览器。
5. 背景大图在导入时按**有损 webp（质量 90）**重新编码：原版画面本身就是有损图，无损再存一遍
   会让 exe 体积翻倍（271MB → 238MB）。文字图层和字体仍按无损导入。
6. **存档 / 读档**（原版完全没有）：`F5` / `F9`，或者右上角开关里的「存档 / 读档」按钮。
   存档文件是 `user://tongfu_qiyuan_save.json`，也就是
   `%APPDATA%\Godot\app_userdata\同福奇缘\tongfu_qiyuan_save.json`（编辑器里跑和打包后的 exe 是同一个位置）。
   除了变量表，还记着隐藏道具收集进度和「存档那一刻停在哪个帧」；读档会跳回那一帧，
   但**不会重跑那一帧的脚本**（脚本效果存档时已经算过一遍，重跑会把属性再加一次）。
7. **隐藏道具图鉴**（原版没有）：右上角常驻开关，点开列出倾城装四件 + 十八里铺淘宝珍品十五种，
   拿到过的显示名字和效果，没拿到的显示 `？？？`。判定点全部照原版脚本走 ——
   帧 297 / 830 / 1317 各送一件倾城装、按钮 1288 是收下羞花衫、帧 968（淘宝成功）按随机数
   `TBWP` 决定淘到哪件（0~13 是十四种珍品，14 以上落到玉如意）。

## 修复记录（2026-09-13）

* **点按钮 / 悬停时闪退**：主程序是在按钮自己的信号里更新界面的，更新时会把正在发信号的按钮一起
  释放掉；编辑器里报「对象被锁住」，打包成 exe 后直接崩。改成界面更新推迟到本帧空闲时执行，
  并且界面改成按 id 复用节点，不再每次换帧重建整套按钮。
* **战斗卡住、没有动画**：关键帧表当初是用模糊缩略图比较出来的，战斗里人物移动 / 出招这类
  局部变化被判成「没变」，画面就冻住了（时间轴其实在走，只是画面不动）。
  改成逐帧精确像素比较后关键帧从 1858 涨到 3512，动画恢复；打包版实测这段动画 6 秒内换了 50 张画面。
  （后来又按原版模型改成「角色独立成层」，关键帧稳定在 2356 个。）
* **战斗里悬停技能按钮后画面回不来**：原版按钮有 `on(rollOut)`（鼠标移开切回原画面），移植版漏了，
  补上后和原版一致。
* **音乐重复播放**：原来靠「文件大小 > 60KB」判断是不是背景音乐，打包成 exe 后 `res://` 里的原始
  mp3 不在包里，判断全部失效，5 首 BGM 都被当音效播放（不循环、还能和别的音乐叠着响）。
  改成按音频时长判断后 5 首全部归类正确。
* **黑衣人被打中之后还在一直挥刀**：以前角色是烧在整幅画面里的，播放头停不下来，只能一直循环。
  现在角色独立成层，并按原版脚本在受击那一帧定格（剧本里点名播动画的写法，例如
  `dr_boos.gotoAndPlay(24)`，也都接上了）。
* **弹出选择框 / 对话框时后面的人物不动了**：原版主时间轴 `stop()` 等玩家操作时，角色自己的
  时间轴还在走；移植版以前把两者一起停住了。现在主循环每帧先推进角色层，再判断要不要等玩家，
  所以菜单出现时后面的人照样在动。
* **大堂那一段「黑屏→大堂」的淡入丢了、边框半透明叠层画反**：那段整屏角色在根舞台最底层，
  抠出去再叠回来会把压在上面的边框 / 底栏画错。这一整段改成直接用原版整幅画面。
* **「老白约会」小游戏里老白大小不对**：那段的人物是按钮（DefineButton2）自己的美术，
  不是角色层那份，同样改成直接用原版整幅画面。
* **（改回原版动画）人物不再独立成层**：上一版把 28 个会动的角色抠出来单独播，确实能做到
  「停帧时人物继续动」，但角色只能画在整幅画面**最上层**，把原版里叠在角色之上的按钮文字
  （战斗的「先机 / 后发」等）盖住了，战斗里会点不到。现已按用户要求改回「人物烧在画面里」：
  画面和原版录制逐帧一致，停帧时不动，但按钮 / 文字 / 点击一律正常。
* **战斗里「后发」→ 选技能没反应**：点技能按钮后画面要切走，按钮节点被摘掉，Godot 会给它补一个
  `mouse_exited` 信号，于是执行了原版的 `on(rollOut)`（切回技能菜单），看起来就像点了没反应
  （技力其实已经扣了）。原版按钮被移出画面时不会触发 rollOut，所以现在被界面摘掉的按钮会打上
  标记，`_on_hover_out` 认出来直接忽略；另外「按钮被就地挪走、鼠标其实还压在上面」也不算移开。
  实测：2162 停帧 →「后发」→ 技能 z，画面停在 2576 继续打，不再被拉回 2171。
* **属性数字浮在对话框 / 说明框上**：原版美术按深度叠，文字框在深度 20~60，弹出来的说明框、
  黑幕在深度 120 以上，会把文字盖住（秀才页悬停「鼓励」时好感 / 对郭芙蓉的情感就被说明框压住，
  无双「时光提示」里掌柜技力 / 修为被对话框压住，战斗闪白时血量同理）。移植版文字单独一层画在
  最上面，就会浮上去。现在生成 `data/hidden.json`（100 帧、283 个文本框），这些帧照原版把被盖住的
  文本框藏起来，逐帧和原版画面比对全部一致。
* **客栈属性的图标悬停看不到说明**：原版按钮带 up/over 两套画，over 那张里就画着说明框
  （「市」→ 容资上市…花费 3500 文 日收入 +400）。移植版以前只画 up 状态。现在把 160 个按钮的
  over 相对 up 多出来的像素抠成 `assets/btnover/*.webp`（一共才 0.3 MB），鼠标压上去按原版位置
  叠一张，位置用「up 状态的可视范围居中于按钮热区」推出来。

### 额外加的功能（原版没有）

* **存档 / 读档**：`F5` 存档、`F9` 读档，图鉴框里也有按钮，存完会在右上角回一句
  「已存档 · 第 n 天 · 时刻」。存档内容 = 变量表 + 隐藏道具进度 + 当前帧号 + 时间轴是否在跑。
  读档故意不重跑当前帧的脚本，避免属性被算两次（例如存档在「得到落雁双坠」那一帧）。
* **隐藏道具图鉴**：右上角常驻开关「隐藏道具 n/19」，点它或按 `Tab` 开框；`Esc` / 点框外也关。
  框开着时下面挡一层黑幕，点不到游戏按钮，`Z` `X` `C` `V` `B` `N` `A` `D` 也不会误发。
  开关位置特意贴在最上沿（y=1），刚好躲开剧情帧右上角的「跳过情节」按钮。
  字体用内嵌隶书（f34），缺的「企 兑 序 灯 猬 瓶 瓷 窑 纹」九个字由系统字体补（`_panel_font`）。
* **花钱之后钱数显示成「500.0文」**：原版数字只有双精度一种，`_sub` 这类运算在 Godot 里返回浮点，
  拼进 `money_tishi` 就带上小数点（淘宝 / 商店买东西之后最明显）。现在 `_add` `_sub` `_mul` `_div` `_mod`
  的结果只要是整数就转回整数（生成器 `tools/build_logic.py` 里的 `_tidy` / `_snum`，重新生成的
  `logic.gd` 其余部分逐字节一致）。存档读回来的数值同样会去掉小数点。

## 开发用工具

```
# 跑一遍所有功能页并截图到 截图预览/
Godot.exe --path game res://dev/shot.tscn -- pages
# 自动跑一遍真实流程（开场剧情 → 战斗 → 营业 → 休息 → 第二天）并截图

# 资源自检（音效时长 / 字体 / 背景 / 角色贴图）
Godot.exe --headless --path game --script res://dev/check_assets.gd

Godot.exe --path game res://dev/anim_shots.tscn
# 悬停/移开探针（验证 rollOver / rollOut 换帧）
Godot.exe --path game res://dev/hover_probe.tscn

# shot 截图到 截图预览/角色动画层/（可加一个帧号只截那一帧）
Godot.exe --headless --path game res://dev/clip_probe.tscn -- state
Godot.exe --path game res://dev/clip_probe.tscn -- shot 2560
# 用真实鼠标事件玩一段，检查闪退（会触发 hover/pressed 信号）
Godot.exe --path game res://dev/input_probe.tscn
```
